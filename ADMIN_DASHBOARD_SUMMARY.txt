================================================================================
BACKEND APIS
================================================================================

admin_stats_api.php
├─ GET: Returns dashboard statistics
└─ Data: farmers, subsidies, markets, scans, recentUsers

admin_users_api.php
├─ GET: Returns farmer list
├─ DELETE: Remove farmer
└─ Data: id, name, email, phone, district, city, pref_lang, role, created_at

get_subsidies.php
├─ POST: Filter subsidies
└─ Data: name, category, description, last_updated

get_market.php
├─ POST: Filter market prices
└─ Data: commodity, market, district, min, max, modal, arrival_date

admin_pesticides_api.php
├─ GET: Returns pesticide mappings
├─ POST: Add/Update mappings
└─ Data: pest_name, brand, name, effectiveness
